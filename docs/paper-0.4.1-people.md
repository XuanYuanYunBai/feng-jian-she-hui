# 0.4.1 人物外观与在途运输

《封建社会》的人物使用 Paper 26.3 的 `Mannequin` 实体。税仓脚夫戴绿头巾、穿围裙。货站脚夫戴蓝帽、挎皮包。世俗领地的代理人穿红袍，教士穿深色长袍和浅色圣带。四张 64×64 像素皮肤随原版资源包分发。

![测试栈道上四套原创皮肤的原版客户端对照截图](screenshots/0.4.1/people.png)

上图在测试栈道上并排放置了四个人形样本，方便比较衣着。游戏中脚夫跟随所属税仓或货站工作，执事、教士在 NPC 持印人的驻地接待来访者。右键驻地代表可打开当地领地档案。[皮肤源图](../assets/npc) · [资源包 ZIP](../examples/imperial-atlas/feudal-people-v1.zip)

## 实服复验

测试使用 Paper 26.3 build 257、Java 25、原版中文客户端，以及普通世界种子 `-2271199516753095334`。服务器从 0.4.0 测试存档升级，按原登记找到旧脚夫，在其实际位置转换为人形。玩家交给队伍的原骡继续服役。

| 场景 | 核对内容 |
| --- | --- |
| 徒步运粮 | 基础脚夫步行运送 8 份小麦。服务端读取人形实体手持木桶的内容，核对起点装货和终点实收。 |
| 驮队满载 | 使用通过原版繁育取得、已登记的成年驯骡。64 份小麦装入骡子的原版驮箱，终点站桶在签收后实有一整组小麦。 |
| 在途重启 | 从保存的货单位置继续行走，既有运单交割后，脚夫与原骡沿栈道回站。 |
| 资源包 | 客户端接受资源包后显示四种服装。测试客户端通过回环地址下载同一个 ZIP。另行核对了默认 GitHub 下载文件与发行包的字节。 |

![原版人形脚夫与载有整组小麦的驮骡](screenshots/0.4.1/caravan.png)

在东境伯领，玩家在仓房门前右键驻地执事。弹出的中文档案显示实际持印人为东境伯家、直辖 256 区块，并列出驻地税权与公库存粮。[执事实景](screenshots/0.4.1/envoy.png) · [右键打开领地档案](screenshots/0.4.1/audience.png)

在 JDK 25 下运行 `mvn clean verify`，25 项测试通过。资源包回归测试核对 SHA-1、四张源图、经典人形 UV 尺寸以及 ZIP 内的实际纹理路径。税仓改建、材料消耗和土地管理操作见[试玩说明](../examples/imperial-atlas/试玩说明.md)。
