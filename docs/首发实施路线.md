# 《封建社会》首发实施路线

[完整十二章设计、数值算例、历史与游戏依据](完整首发原案.md)和[历次里程碑](slg-design.md)共同构成首发范围。项目以可持续的多人 SLG 为目标，允许三代无地经营，也允许从首庄走到帝国政治。现行优先级与比例以本表及[领地、建筑与有限经济增订](领地建筑与有限经济.md)为准。

|顺序|交付内容|验收局势|

## 已锁定的比例与制度

- 首庄登记 100 人，分庄实迁 300 人且原庄至少留 100 人。合格民房一张床代表 100 人。200 名本庄居民、合格议事厅、充分住房且持续一季公共服务可建领，单案 36 区块，边地开拓单案 16 区块、每四区块 100 人。住房不足先拥挤。自营生活使用有限劳力，扩张与销售由玩家决定。
- 一份面包供 100 人一季，小数跨季结算。满供且有空房时基础增长 2%，余粮与空床另提供至多 6 个百分点。连续首季短缺减劳力、次季有去处方可迁离，连续第三季及以后且当季供养低于一半，首测死亡为缺粮人数的 5%。空服暂停，默认每六个活跃小时一季。
- 原案中强制放弃飞地、固定直辖面积和最低四成税收由距离衰减至零的自动征收取代。亲临产地可全额提取应税实物。王封公、公封伯，伯爵以下授庄园、修院与收益。流官不能自扩或转封，增拨受 256 区块上限约束。
- 帝国是独立国家之间的特殊组织，帝内王国须专门协商。法理归属、实际掌印、宗主、国际组织成员分别登记。产权、税权、居住地各自记账。
- 玩家可改建起始税仓。货物、金银、赈济、役畜均有实际来源。沿路收费亭以金银标价，陆水联运实际换装。玩家野外重载受限，深水靠桥船，合法渡口上下。交易用备货备款的玩家订单，浮动价取真实成交。
- 每个阶段用自然随机地形、Paper 和 BlueMap 回归。记录预置条件，全新安装、升级、崩溃恢复分别验证。提供原版客户端截图、动作短片、可安装包与 GitHub 提交。原案 51–77 人周是全首发初估。

## 0.11.0 交付位置

首庄、室内床位、人口归属和旧户数迁移已接入 P0。P1 已可完成供粮、出生、饥馑、农事工班与直接陆路迁居。诊断顺序是先查季报缺多少人份，再看仓里有没有熟食、工班是否交粮、房里有没有空床。庄簿显示本庄收支，人口簿按实际辖区汇总。[操作与实服验收](paper-0.11.0-residents.md)

下一轮优先把庄园的季粮缺口接到 P2 的跨庄赈济。先由缺粮庄开出明确数量的请求，再由供粮庄从实仓备货、安排有路费的承运者，经已登记的陆站和渡口分段交付，最后以签收数量重算缺口。验收时在换船前拆桥、封渡、填满目的仓、重启服务器，分别检查货物位置、是否重复扣仓，以及两庄下一季的人口。封臣和流官的减征授权随后接在同一份赈济账上。

## 0.12.0 交付位置

P0/P1 已接入主宅与公共议事厅、200 人建领和随余粮及空房变化的自然增长。P2 已接入实仓跨庄赈济和铁件补路。P3 已可在治所双方交印，随交接改变实际管辖人口。P4 已可由领地设立有限矿场，给经营者签特许，派工人领镐、采矿、交仓。玩家在九支中文建筑图谱中可查看每项设施的当前开放情况。[操作、边界及测试截图](paper-0.12.0-land.md)

后续按依赖推进。先补多段赈济的同单追踪、改建与断运恢复，再做公共工程养护和减征授权。矿冶的下一步是矿体品位、排水与更深工作面。粮、工时、金属、桥路已有实物与辖权账后，再接征召、军营、军械订单、围城和离线守备。每项的完整上下游与验收场景见[建筑分支表](领地建筑与有限经济.md)及完整原案。

## 0.12.1 交付位置

P2 的跨庄赈济已接入同单水陆联运。供粮庄按首尾实际厅仓委托公共货线，每段在同一个站桶交接，过路费沿用各段规则。断路、封航、交仓位被占和正常停服重启纳入验收。赈粮签收后成为可扣的季粮。后续接入公共工程养护、地方减征授权与多支货队并行。[实测与操作](paper-0.12.1-relay.md)
