# 《封建社会》0.13.0　家族、婚书与继承

在主世界生存模式输入 `/realm family` 打开中文家档。初代有一位 28 岁的代表和一位 23 岁的同胞；已有庄园的玩家可以直接查阅名下庄产。点击「题家名与家徽」登记家名、代表姓名和文字家徽。每个账号同时经营一个在世家族，每次只操控一名代表。普通亲属留在亲谱中，保有出生、双亲、家籍、居所和房支记录。

## 第一次交接前可以做什么

| 家档页面 | 玩家操作与效果 |
| --- | --- |
| 本家、亲谱 | 查看人物号、年龄和住处。尚无居所的成员可在自家庄园落籍，占用已有居民名额。亲属远迁要先取得目的庄的寄居、租住或婚居资格。到原庄选「陪同」，沿途走路或乘船，到目的庄办「到庄」。途中换代表可在上次地点「接回」，目的庄已满可护送返乡。 |
| 婚约 | 可为已落籍的成年成员登征婚帖，或从本庄未具名的居民中结婚。跨家婚书约定居住庄、子女家籍、嫁资及配偶身后的按季供养，两家代表到拟约庄厅会签。签婚不移动配偶。夫妻同住后，约定接纳子女的一方可启用养育。每年一次机会，须当季庄簿已有出生，成功时从其中一人登记为子女。 |
| 亲谱、婚约 | 在本庄铁匠铺或议事厅登记学徒。跨过一季，并取得两份新的对应工单或季报回执，方可出师。业主可将铁工或查账委托给本地出师的成员。幼主可以指定成年监护人，摄政期间保留原约，重大授地、让渡和改约须等成年。 |
| 家产 | 查看私庄、商站、已登记封银的权利人和共有份额。成年族人取得本地私庄并居住后，可在那里分房。另持领印的成年族人可在治所授予代表限定期限的「亲收税箱」或「交印」权。无地时可用实际营桶、铺位、屋盖和营火扎营，也可向其他庄主求宿或接已有货款的实物委托。 |
| 继承预览 | 生前逐项查看接续人、私产和头衔各归谁。可登首选接续人，或在同庄成年亲属之间生前交棒。交棒的原代表在世时仍可保有其职权。普通、优先和联盟分割，以及长嗣、幼嗣、年长者家法分别计算。联盟分割需要满足已有的建领条件。 |

**生存死亡立即结束本代。** 复生后从合资格的人选中接续，亲谱保留死者。归属其他家族的子女仍可能按文书分得私产。选任、任命与世袭头衔分别按其制度交接，公库沿用原公账。随身实物按死亡掉落规则留在现场，继承人须自行寻回。绝嗣后旧家档封存，账号可另建新家；旧家的库银和领印不会随账号转来。

## 怎样交付一笔嫁资

1. 在「婚约」写明数额，由双方在庄厅签署。查看婚书上的应付额。
2. 付款家将带印的银币放入本庄登记私柜第一格，空出第九格，在柜边办理「封嫁资」。原银装入有编号的封桶，超额部分留在柜内。
3. 从柜里取出封桶运往收款庄，将原封桶放入对方登记私柜第一格。收款家到柜边「付嫁资」。验收后第九格收到银币，婚书写入已付额。遗属按季供养也要实物交割。
4. 想将剩下的银币计入可分遗产，可在自家柜边「封存」并给银包起代号。分割产生收益份额；领取银币时仍要到实柜办理。「借出」使用已封存的实银，本版签借须两家到场并提供等额担保。寄居租约约定的是有期限的居住权。

## 实机验收

使用 Java 25、Paper 26.3 build 257、BlueMap 5.29，在从 0.12.2 升级的普通随机地形运行。世界种子为 `-2271199516753095334`。为复现交割，测试预置了两个庄园、税箱、桥面和私柜，并在付款柜中放入 33 枚实银。截图来自两个原版中文客户端。

| 场景 | 实测结果 |
| --- | --- |
| 双家会签 | 两名非管理员玩家分别操作自己的家档，在庄厅签下婚书。[婚书画面](screenshots/0.13.0/marriage.png) |
| 带税箱死亡换代 | 玩家亲收税箱，控制台在生存模式触发死亡。停服后对照实体区块、玩家背包与 SQLite：死者有一份结算，妹妹接掌柳岸庄产和领印，原税箱在地面，公库入账为零。[换代结算](screenshots/0.13.0/succession.png) · [换代后亲谱](screenshots/0.13.0/pedigree-release.png) |
| 履行婚约 | 从付款柜取出封好的 3 枚银币，步行过河，在收款柜交割。复核两个存盘区块：原庄后来封存的 30 枚与收款庄的 3 枚合计 33 枚，收款柜原有的 6 个面包仍在原位。[付款庄的桶](screenshots/0.13.0/purse-cabinet.png) · [到达收款柜](screenshots/0.13.0/receiving-cabinet.png) · [签收后的婚书](screenshots/0.13.0/marriage-receipt.png) |
| 家产与地图 | 重启后可查询已封存的 30 银和死亡结算。BlueMap 对照数据库复核了 773 个领地区块、2 座桥亭、7 条线路、4 个泊位和 2 座商站。[继承预览](screenshots/0.13.0/estate-forecast.png) · [家产页](screenshots/0.13.0/holdings.png) |

本版构建运行 66 项测试。三代接续、先亡支系代位、各类财产权分割及年度生育防重复采用推进季序的 SQLite 用例。多人实服覆盖了会签、身故、续代、运银和重启；三代自然时间、陪迁途中换代、实物借据清偿和大规模同时交割尚未完成多人全程验收。

安装时停服备份原世界与插件数据库，将旧 FeudalSurvey JAR 换为 [0.13.0 插件](../examples/imperial-atlas/feudal-survey-0.13.0.jar)，保留数据目录后重启。旧庄主首次进主世界时按其原身份登记家档。停服存档复核脚本提供死亡现场和嫁资交割两种检查，适用于上述预置场景。[核验脚本](../tests/paper/verify_family.py)
