# 《封建社会》0.15.0 · 一车小麦如何等到断路修通

领内的公共货线缺了一块路面，已经出发的脚夫会带货等在断点前。地方持印人可以自备材料，也可以立案，让当地商户自愿定价收购一件桥路铁件。打开经营簿里的「公共养路簿」能看见缺口坐标、谁出了钱、谁供了料、谁到场修路，以及这一段是否已经验通。[下载插件](../examples/imperial-atlas/feudal-survey-0.15.0.jar) · [新玩家从安家到建领的试玩地图和说明](paper-0.14.0-playthrough.md)

## 在游戏里办理

| 场合 | 操作 |
| --- | --- |
| 发现断路 | 缺口所属区块的持印人站在旁边，瞄准缺失路面下方或侧面的支撑方块，打开「公共养路簿 → 勘查眼前缺口」。同一个方块只开一件待办案。对象限已登记公共陆线的中段，站桶需重建，航段另查渡口。 |
| 筹料 | 工程所在领地的商柜业主把实钱放进自己柜桶的第二格，在柜边打开工程，选自己的商柜，填写一件铁件的价格与金银币种。每单收一件，定价为 1 至 64 枚。立案后可登记预算，成交时才有实付金额。柜主抽走款项后，交割会等待补款。 |
| 锻铁与交割 | 庄主在已登记铁匠铺备一锭铁、一份木炭和四个本庄工时，派铁匠锻造。交料人将成品送到出资柜，放入第一格，打开订单交货，从第三格取款。柜主从第四格及以后的收存格取铁件。不同人承担出资与修路时，须在世界里交给施工人。 |
| 修路与验收 | 持印人把铁件拿在主手，木板拿在副手，回缺口瞄准支撑面，点「修补眼前缺口」。桥墩、邻侧路面和净空要能支持通行。用掉的铁件、木板种类、经手人与季次记入工程簿。在现场六格内点「现场验通」结案。自备料的工程可直接施工。货队按路面实况恢复行进。 |
| 放弃工程 | 持印人在工程页选「终止本案」并确认。有待交割的订单时须到出资柜撤单，柜主也可依市场规则撤下自己的报价。未成交的款仍在柜中。已经完成的交易保留实付记录。 |
| 查图与查档 | 在 BlueMap 图层菜单打开「待办道路养护」，可按工程号定位缺口。验通或撤单后地图移除该标记。游戏内输入 `/realm works` 仍可翻查结案记录。 |

资金目前来自一位出资人的实柜。多户分摊、公库拨款和路面按季损耗留待后续。登记货线沿用已有的管理员设施登记流程。

## 双人实服记录

在 0.14.0 建领与换代实测存档的副本上更新插件。普通主世界种子为 `-2999477474165736077`，服务端为 Paper 26.3 build 257，使用 BlueMap 5.29。两个无 OP 权限的原版客户端分别扮演持印人和供货人。控制台预置货线、料桶、金粒与施工木板，并把角色带到各测试起点。领主从柜台领件到断路处这一程由客户端步行完成。

| 经历 | 实际结果 |
| --- | --- |
| 断路与开价 | 管理员登记了 26 个路面位置，测试拆下其中一块。载有 4 份小麦的脚夫停在第 9 步。无领印的供货人不能勘立此案。领主柜里只放 2 枚金粒时，3 枚的收购单无法成立，补到 3 枚后才开单。[勘查](screenshots/0.15.0/survey.png) · [预算](screenshots/0.15.0/funded.png) |
| 成交与重启 | 铁匠完成三次锻打并把铁件交仓，供货人到柜交料，领取 3 枚金粒。此时 BlueMap 报「养路 #1 · 已购料待验」。在这一步停服重启，铁件仍在柜内，货单仍停在第 9 步。[柜台成交回执](screenshots/0.15.0/paid.png) |
| 修复与送达 | 领主带铁件走回现场，先尝试验收，系统提示路面尚未通行。随后实际消耗一件铁件、一块橡木板，补好缺口并验通。原货单继续到第 25 步，收货人签收，终点桶内有 4 份小麦，起点桶已空。[修前工程簿](screenshots/0.15.0/at-site.png) · [验通账](screenshots/0.15.0/accepted.png) · [终点桶](screenshots/0.15.0/wheat.png) |
| 别家出资与撤单 | 在第二处缺口，上一案的供货人用赚到的 3 枚金粒在另一家商柜出资。领主尝试交普通铁锭，成交被拒。他在出资柜终止订单后，实付为零。停服核对，第一格仍有一锭普通铁，第二格仍有 3 枚金粒。BlueMap 待办图层清空，货线保留。[商户出资](screenshots/0.15.0/subscription.png) · [撤单确认](screenshots/0.15.0/cancel-form.png) · [撤单回执](screenshots/0.15.0/withdrawn.png) |
