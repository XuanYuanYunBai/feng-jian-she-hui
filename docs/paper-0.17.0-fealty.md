# 0.17.0　换代效忠与庄园供养季账

## 两家怎样行礼

1. 双手留空，潜行按交换副手键，打开经营簿的「本家效忠誓书」。家档可以进入「核对当代誓书」，领地详情也可以查本领誓书。
2. 选择一份封契，查看当代封臣、直属封君和治所区块。两名玩家同到该区块，相距十二格以内。封臣点「当场行效忠礼」，封君点击收到的提示，或从自己的经营簿进入同一份誓书。
3. 封君点「当面接受誓言」。账中分别留下呈誓季和受誓季。两边都须到场，离开治所后要等对方回来再办。
4. 任一方身故、代表交棒或封契改隶后，受影响的旧誓书归档。前代只呈未受的也归档。继承人接印后依当前的直属关系另行宣誓。一位封君有多个封臣，各份誓书分别办理。

新誓生效前，该持印人若想以此领为上级转封、授予收益或向上请袭，需先完成当代效忠礼。领地继承、实仓存粮和既有收益仍依各自文书处理。法定任命与实际掌印有争议时须先解决印权。自领上下两印时显示「一人兼领」。独立国家单凭帝国成员身份不会产生直属封契。

一方为非玩家持印人时，由治所在真人到场后代为应礼。纯 NPC 的两家没有自主集会行礼流程。旧存档中缺少誓书的封契，从两位现任持印人开始立誓。

## 庄主要怎样查公共服务

在庄档点「历季公共供养账」。每页六季，显示期初和期末人数、实际开出多少面包、差多少人份、公粮是否达到三份、服务时间是否满一季。口粮足、季末余粮至少三份且供养满一季，才累计连续服务。访客可以核验达标原因，私仓余额仍由庄主查阅。升级前的季报沿用已知人口和耗粮数，缺失的公粮与时间凭据标为「旧季未留公粮及时间凭据」。

## 两个原版客户端的验收记录

使用 Paper 26.3 build 257、BlueMap 5.29、中文原版客户端和普通地形随机种子 `-2999477474165736077`。从已建领、已授出东岸粮租的 0.16.0 河台庄测试档复制。为在一次联机测试中触发两边换代，事先各置一名成年男嗣，并调整封君的出生季。管理员将双方送到治所并触发人物死亡。玩家客户端点选继承人、呈誓和受誓。

| 誓书 | 封臣 → 封君 | 发生了什么 | 存档结果 |
|---|---|---|---|
| #1 | NewReeve → 儿子4 | 第 176 季双方签成，随后封臣身故 | 已终止，保留呈誓和受誓季 |
| #2 | 北岸继嗣 → 儿子4 | 第 176 季新封臣呈誓，封君在受誓前身故 | 已终止，受誓季为空 |
| #3 | 北岸继嗣 → 河台继嗣 | 第 177 季呈誓；封臣离场时受誓被拒，重返治所后第 178 季受誓 | 已受誓，仅此份生效 |

河台庄第 178 季期初和期末均有 200 人，实开两份面包，缺口为零，公粮与时间均达标。同页还可查到升级前第 174 季的原始人口、耗粮和凭据缺项。
