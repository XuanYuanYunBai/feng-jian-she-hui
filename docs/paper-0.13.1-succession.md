# 《封建社会》0.13.1　谁接续玩家，谁接掌领地

打开 `/realm family` →「继承预览」。页面上方列出**能作为下一代游玩的男性**，下方逐项列出庄产、存银和各枚领印的归属。同一位玩家控制数领时，几枚领印可以分别传给不同的人。

| 玩家要判断的事 | 本版规则 |
| --- | --- |
| 身后能操纵谁 | 先列本家在世的男性后裔，先亡儿子可由本家男性后裔代位。无人时再列本家在世兄弟。生前的首选只能从当前顺位中挑。 |
| 女儿与外孙怎么办 | 女儿保留亲谱、财产、居所和婚约。新婚书的子女随父家入籍。前两层都无人时，乡户等 AI 家族的外孙才列入接续名单。选定后只有该外孙入本家，亲谱保留父母关系，账册保留其原家籍。人类玩家家族的外孙即使离线也不能被另一个账号接管。 |
| 私产怎么分 | 登记的私产和封银依本家家法结算。没有合资格男嗣时可由合资格的 AI 外孙继承。嫁资、遗属供养仍按婚书的签约家族办理。 |
| 领印怎么传 | 到领地治所，在「继承预览 → 领地继承法」登记资格和次序。**父系男嗣**沿父系寻找男性；**女系递传**在父系无人时允许女儿将资格传给自己的儿子。两项都不把女性本人列作继承人。每领可沿用家法，也可单设长嗣、幼嗣、年长者。流官任命和选侯议帝沿用原有程序。 |
| 玩家家族的外孙能得到什么 | 允许女系递传的领地可以把领印交给他；他继续属于自己原来的玩家家族。另一领使用父系男嗣法且无人合格，就留下空缺。用 `/realm heir 头衔代号 人物号` 提名前，系统会按该领法律核验。 |

例如，祖父只有两个女儿。长女的儿子属于另一位真人玩家，次女的儿子属于乡户。祖父可以为采用女系递传法的磨坊收益封契提名长女的儿子。祖父去世后，玩家能选择接续的是次女的儿子。磨坊收益、外孙的家籍和玩家的下一代各有自己的交接记录。[分领预览](screenshots/0.13.1/two-laws.png) · [两名外孙的亲谱](screenshots/0.13.1/grandsons.png) · [接续名单](screenshots/0.13.1/foreign-choice.png)

## 在路上换代

从「亲谱」陪同族人出发。庄簿先把同行人从出发庄减一，目的庄要等到场才加一。代表途中身亡时，亲属在死亡地点等候。在出生点打开亲谱可看等候坐标；继承人要走到六格内「接回」，再陪到目的庄办理「到庄」。若原来的接纳文书在路上失效，可以续约或护送返乡。陪同家族已无合资格代表时，路过的另一家可在六格内援送；原目的地仍须有接纳资格。

## 随机地图实测

用两个非管理员原版中文客户端，在 Java 25、Paper 26.3 build 257、BlueMap 5.29 中，从 0.13.0 的普通地形存档升级。随机种子为 `-2271199516753095334`。为复现特定亲缘关系，测试预置了两家的儿女、父家不同的两名外孙、现有领印和目的庄的空床；签定领法、提名、护送、接续都在游戏内操作。前两个场景由控制台在生存模式触发死亡；最后一轮亨利在治所测试平台意外坠亡，也触发了实际交割。

| 场景 | 核验结果 |
| --- | --- |
| 妹妹在世，儿子接续 | 系统拒绝把妹妹设为首选，也拒绝死亡后用她的人物号接续。儿子亨利取得代表身份。[首选预览](screenshots/0.13.1/male-preview.png) · [身后交割](screenshots/0.13.1/male-succession.png) |
| 护送途中死亡、停服再启 | 东岸原有 300 人，妹妹离庄后 299 人，父亲在途中死亡后 298 人。重启后儿子步行回到等候处，陪妹妹走到粮庄。粮庄从 100 人增至 101 人，重复办理没有再加人。[在路上](screenshots/0.13.1/on-road.png) · [到庄后的亲谱](screenshots/0.13.1/arrived.png) |
| 外孙来自两家 | 真人父家的外孙获准继承磨坊收益，在另一座父系领被拒；他继续留在父家。祖父去世后，玩家只能迎回乡户外孙。停服账册分别记录了领印持有人、两名外孙各自的家籍与入继记录。[入继后的家档](screenshots/0.13.1/ai-successor.png) |
| 一位领主的两种长幼次序 | 亨利在两领治所分别登记长嗣和幼嗣，随后坠亡。上游公领由长子取得，河间地由幼子取得；账号选择幼子后，长子的官印仍归长子。[两枚领印的去向](screenshots/0.13.1/birth-order.png) |

BlueMap 同服核对了 773 个领地区块、2 座桥亭、7 条货线、4 个泊位和 2 座商站。亲谱、家籍与婚约只在游戏内查看。[重启后亲谱](screenshots/0.13.1/adopted-pedigree.png)

本版有 71 项自动化测试，覆盖旧档迁移重入、不同领法、三代接续和财产分配。旧版没有记录性别。迁移按旧版固定的创始人与姐妹身份补录，已有子女在升级时一次性登记性别并保存。旧制中已接班的女性退居，既有私产与领印保留在她本人名下。家中仍有合资格男性时可重新选代表，无合资格人选时旧档保留，可以另立新家。升级前请停服备份世界和插件数据库。
