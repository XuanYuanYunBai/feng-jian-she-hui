# 河湾第一车

西岸粮栈有 24 份小麦要交给东岸织坊。两站之间只有一座木桥。你可以独自押运，也可以让另一名在线玩家到东岸等车。

## 开服

将试玩 ZIP 解压到新的空目录，加入 Paper 26.3 build 257 服务端 JAR，用 Java 25 启动。按 Paper 的首次开服流程设置 EULA 和玩家白名单。包内包含世界、登记好的货线、插件和本地图的服务端设置。世界与货运账本共同保存站桶身份，请一起使用。

## 第一单

1. 到西岸粮栈。起点站桶埋在路面，坐标为 `-14 62 0`。旁边 `-16 63 -2` 的箱子里有普通书和修桥用的橡木板，各拿一份。
2. 主手持书右键起点桶，点击 **填写货单**。聊天框会填入货线和新运单号。自己签收可直接发送。若由同伴签收，在末尾填上对方的在线玩家名再发送。
3. 沿路跟车。车停在桥上时，输入 `/freight status` 查看受阻坐标。用一块橡木板补齐桥面 `1 62 1`，货车会继续向东。
4. 到东岸织坊站桶 `14 62 0`。指定收货人主手持书右键站桶，点击 **签收**。待状态显示已交付后，空手开桶，第一格可取出原来的 24 份小麦。
5. 用 `/freight status 运单号` 查看签收回执。再次发货需要在西岸桶中放入新货并使用新的运单号。粮栈旁的麦田可以收割。

## 场景源文件

`build.mcfunction` 记录了制作场景的原版方块命令，可在仓库中编辑。它面向地表 Y=62 的专用平坦测试世界，会改写 X、Z 各 -24 至 24 范围的场地和容器。布局生成后，在控制台执行 `freight route riverbend -14 62 0 14 0` 登记站桶。试玩 ZIP 已完成登记。
