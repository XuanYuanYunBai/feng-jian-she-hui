# 河湾帝国 · 0.3.0 试玩

将同目录的 `feudal-survey-0.3.0.jar` 放入 Paper 26.3 build 257 的 `plugins/`，使用 Java 25 启动。升级 0.2.0 时替换旧插件 JAR，保留原有插件数据目录。启动后请一位玩家上线，管理员执行 `/realm init 玩家名`。这只会建国一次。君主和封臣日常操作均可由普通权限玩家执行。

## 看地图，找到自己的税源

输入 `/realm` 打开可点击的政治图册。点击领名可翻阅法定任命、实际持印人、驻地、领界和财权。点击“疆域图”取得全图，低头看手中地图，右键可返回图册。`/realm local` 展开身边 25×25 区块的地图。`/realm here` 查询脚下土地，`/realm depots` 给出税仓中心的方块坐标。在地表找带名字的木桶，右键打开税账。

建国以主世界出生区块为原点。王城、东境伯领和主教驻地各有 16×16 个区块，后两处分别在王城以东 1024 格和 2048 格。未登记土地也会在图册查询中明确显示。辖区可以沿实际区块边界划成不规则形状。

## 亲自走一趟

| 地点 | 默认首期应收 | 自动入公库 | 可亲征 |
| --- | ---: | ---: | ---: |
| 王城市集 `town` | 16 | 16 | 0 |
| 王城以西 80 格的西磨坊 `mill` | 16 | 8 | 8 |
| 王城以东 112 格的东渡仓 `ford` | 16 | 0 | 16 |

先执行 `/realm ledger` 查看全领税仓。走到东渡仓五格内，在税账点击“在此亲征”，或输入 `/realm collect ford`。选中封缄税桶，运回王城中央库址，执行 `/realm deposit`。用 `/realm treasury crown` 查看到账存粮。西磨坊只能领取本期剩余的八份。税仓已分封时，未收款由当前持税权者领取。换手之前已入公库的粮和已封箱的归属保留原收款方。

每累计约 20 分钟有玩家在线的游戏时间进入下一税期。旧期欠额可用 `/realm collect 仓ID 税期` 在原地领取。若服务器在装箱时中断，原征收者可回仓执行 `/realm reissue 仓ID 税期` 重领同编号税箱；每个编号只能入库一次。每个税仓每期产生 16 份试算小麦。持印人可在自己管辖的区块使用 `/realm depot 仓ID 仓名` 登记新税仓，下一期开始计税。

前往直属封臣的驻地时，玩家持印人可以用 `/realm gift 本领ID 数量` 从本领余粮中赠纳。君主到访 NPC 驻地可用 `/realm visit 本领ID` 提出请求，每税期答复一次。NPC 至少留下 12 份口粮，地方势力越稳固，愿意追加的赠粮越少。任命争议期间谢绝赠纳。

## 授地与划界

坐标均为**绝对区块坐标**。矩形参数依次为西、北、东、南，含两端。在负方块坐标也按向下取整换算。授地仅能从自己的直辖地划出，须保留授予者驻地；已有独立收益封契的区块须保留原有权利。位于示例坐标原点以外的世界，请把所有示例坐标平移到实际王城。

| 命令示例 | 结果 |
| --- | --- |
| `/realm register crown 8 -8 23 7` | 君主把共边、无人持有的土地登记为直辖地，每次最多登记 256 区块 |
| `/realm preview crown 公爵 river 河东公国 玩家名 4 0 7 2` | 在自己的地图看选区；用相同参数将 `preview` 换为 `grant` 即颁发封契 |
| `/realm grant river 伯爵 fordcount 东渡伯领 玩家名 7 0 7 1` | 公爵将两个区块封给伯爵 |
| `/realm estate fordcount 庄园 farm 渡口庄园 玩家名 ford` | 授予东渡税源收益，管辖和效忠关系保留在伯领。种类还有修院、磨坊和地租 |
| `/realm grant crown 流官 gov 北部行署 玩家名 8 -8 22 7` | 任命流官治理 240 区块 |
| `/realm estimate gov 23 -8 23 7` | 地图显示追加后合计 256／256，核对后用 `extend` 替换 `estimate` 生效 |
| `/realm patent crown 修院 west 西岸修院 npc-Abbot -7 2 -6 2 维护驿道` | 皇帝另立直属特许并记录条件。可授伯爵、城市或修院 |

普通封契由皇帝或国王授公爵、公爵授伯爵。伯爵以下可授庄园等收益。流官的所有辖地跨职位合并计算，任何一次超额追加整笔回退。受封者可写在线玩家名，或用 `npc-名字` 指定署理家族。已入账的土地、官印与税物随世界重启恢复。

## 任期、家产和官印

1. 持印人用 `/realm heir 头衔ID 人名` 提名家族继任人。在本领境内，其他玩家可用 `/realm support 头衔ID` 联署，每个任期每人一次。每度过一税期增加一点任职资历，最多两点。
2. 积累至少两点联署或资历后，持印人可用 `/realm petition 头衔ID` 请袭。上级用 `/realm confirm 头衔ID` 明确准许。世袭家族也可用 `/realm relinquish 头衔ID` 交回该项特权。
3. 持印人用 `/realm vacate 头衔ID` 触发该职出缺。已登记的家产按各自文书交给继承人。普通官职由提名者暂管；有准袭文书的官职直接交接。公库始终挂在头衔下。
4. 上级用 `/realm appoint 头衔ID 人名` 颁发任命书。新任与持印人为同一人时立即结案，否则由实际持印人执行 `/realm yield 头衔ID` 或 `/realm resist 头衔ID`。NPC 持印人由直属上级请求执行，支持和资历不足两点时接受交印，达到两点时抗命。任何人都可以用 `/realm brief 头衔ID` 核对两人的身份，用 `/realm acts 头衔ID` 查阅文书。

## 帝内王国与独立和约

皇帝使用 `/realm offer 公爵领ID 王号 协议条件` 拟约，公爵用 `/realm ratify 公爵领ID` 接受，成为仍向帝国效忠的国王。日后只有帝内国王能以 `/realm offer 王国ID 独立 和约条件` 提议独立，皇帝签署后才解除上级关系。两次协议各自保留在文书记录中。王号和隶属关系即时生效，具体军事勤务以文字条款留档。

自动税距按税仓到本领驻地的东西、南北区块数之和计算。默认三步以内自动全收，第四至第六步依次为 75%、50%、25%，第七步归零。可在 `config.yml` 把 `realm.chunks-per-tax-step` 从 1 改为 2，重启后对新税期生效。每两区块算一步，余数进一；亲征额度仍按剩余应收计算。
